# واژه‌راه | آموزش لغات انگلیسی به فارسی

**واژه‌راه** یک اپ مستقل برای یادگیری مقدماتی واژگان انگلیسی با معنی فارسی است. با درس‌های کوتاه، آزمون چندگزینه‌ای و تمرین روزانه می‌توانید دایرهٔ لغات خود را قدم‌به‌قدم گسترش دهید. واژه‌راه برای فارسی‌زبان‌هایی طراحی شده که می‌خواهند یادگیری زبان انگلیسی را از واژه‌های ساده شروع کنند.

> **محدودهٔ نسخهٔ فعلی:** این پروژه به دولینگو وابسته نیست و به حساب، مراحل یا محتوای آن دسترسی ندارد. دورهٔ کنونی مقدماتی و اختصاصی است؛ زبان‌های دیگر و دوره‌های پیشرفته هنوز ارائه نشده‌اند.

## امکانات

- آموزش واژگان انگلیسی با معنی فارسی در **۴ بخش، ۱۲ درس و ۴۸ واژه**
- درس‌های کوتاه با مرور کلمات و تمرین چندگزینه‌ای
- تلفظ کلمات انگلیسی با موتور گفتار مرورگر یا اندروید، در صورت پشتیبانی دستگاه
- باز شدن مرحله‌ها به‌ترتیب و امکان مرور درس‌های تکمیل‌شده
- واژه‌نامه، امتیاز تجربه، دستاورد، هدف روزانه و شمارش روزهای متوالی
- رابط فارسی و راست‌به‌چپ، قابل استفاده در موبایل و دسکتاپ
- ذخیرهٔ پیشرفت و تنظیمات روی همان دستگاه، بدون نیاز به ساخت حساب

## دانلود اپ اندروید

از [بخش انتشارها](https://github.com/pooria683/Persian-Doulingo/releases) فایل APK نسخهٔ آزمایشی را دانلود کنید. برنامه از اندروید ۶ (API 23) به بالا پشتیبانی می‌کند و برای نمایش درس‌ها به اینترنت نیاز ندارد. اگر نصب از خارج از فروشگاه غیرفعال است، باید در تنظیمات دستگاه به مرورگر یا برنامهٔ فایل‌ها اجازهٔ نصب بدهید. برنامه برای نمایش صفحه‌ها از Android System WebView استفاده می‌کند؛ در صورت وجود مشکل، آن را به‌روز کنید. تلفظ به موتور گفتار و صدای انگلیسی نصب‌شده روی دستگاه بستگی دارد.

پیشرفت فقط در حافظهٔ همان برنامه یا مرورگر ذخیره می‌شود، با حذف برنامه یا پاک کردن داده‌ها از بین می‌رود و بین دستگاه‌ها همگام نمی‌شود. نسخهٔ اندروید اولیه است و آزمایش روی دستگاه واقعی در این محیط انجام نشده است.

## اجرای نسخهٔ وب

به Node.js نسخهٔ ۱۸ یا بالاتر نیاز دارید؛ بستهٔ خارجی نصب نمی‌شود.

```sh
npm start
```

سپس `http://localhost:3000` را باز کنید. برای تغییر درگاه، متغیر محیطی `PORT` را تعیین کنید. آزمون‌ها با `npm test` اجرا می‌شوند.

## ساخت APK

برای ساخت محلی به JDK 17، `android.jar` مربوط به یک SDK جدید اندروید و ابزارهای SDK شامل `aapt`، `d8`، `zipalign` و `apksigner` نیاز دارید. یک keystore خصوصی و پایدار برای امضای انتشار خود بسازید و در محلی امن نگه دارید؛ آن را در مخزن قرار ندهید. برای نصب یک نسخه به‌عنوان به‌روزرسانی نسخهٔ قبلی، باید از همان کلید امضا استفاده شود.

```sh
export JAVA_HOME=/path/to/jdk
export ANDROID_JAR=/path/to/android-sdk/platforms/android-35/android.jar
export ANDROID_BUILD_TOOLS=/path/to/android-sdk/build-tools/35.0.0
export SIGNING_KEYSTORE=/secure/path/release.keystore
export SIGNING_KEY_ALIAS=your-key-alias
# این دو مقدار را از یک روش امن و خارج از مخزن تنظیم کنید:
export SIGNING_STORE_PASSWORD='...'
export SIGNING_KEY_PASSWORD='...'
./android/scripts/build-apk.sh
```

فایل امضاشده در `android/build/` ساخته می‌شود. رمزها و کلیدهای واقعی را در مخزن یا دستورات ذخیره‌شده قرار ندهید.
