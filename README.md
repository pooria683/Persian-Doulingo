# واژه‌راه

یک اپ مستقل و فارسی‌زبان برای تمرین معنی واژه‌های انگلیسی. این پروژه وابسته به دولینگو نیست و از دوره‌ها، حساب یا پیشرفت آن استفاده نمی‌کند. فایل ZIP ارسالی فقط بخشی از دارایی‌های مرورگر دولینگو بود و محتوای کامل دوره‌ها یا سرور آن را در بر نداشت.

نسخهٔ فعلی یک دورهٔ مقدماتی اختصاصی شامل ۴ بخش، ۱۲ درس و ۴۸ واژه دارد؛ زبان‌های دیگر و دوره‌های پیشرفته هنوز تهیه نشده‌اند. مرحله‌ها پشت سر هم باز می‌شوند و مرور درس‌های تکمیل‌شده هم امکان‌پذیر است. پیشرفت، امتیاز، روزهای تمرین و تنظیمات در localStorage همین مرورگر ذخیره می‌شوند؛ با پاک‌کردن داده‌های مرورگر از بین می‌روند و بین دستگاه‌ها همگام نمی‌شوند. تلفظ از قابلیت گفتار مرورگر استفاده می‌کند و به پشتیبانی مرورگر و صداهای نصب‌شده وابسته است.

## اجرا

به Node.js نسخهٔ ۱۸ یا بالاتر نیاز دارید؛ هیچ بستهٔ خارجی نصب نمی‌شود.

```sh
npm start
```

سپس `http://localhost:3000` را باز کنید. برای تغییر درگاه، متغیر محیطی `PORT` را تعیین کنید. آزمون‌ها با `npm test` اجرا می‌شوند.
